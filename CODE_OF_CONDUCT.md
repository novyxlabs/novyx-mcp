# Code Of Conduct

Novyx MCP follows a simple rule: be direct, technical, and respectful.

We welcome bug reports, install fixes, docs improvements, and integration
examples. We do not tolerate harassment, personal attacks, spam, or attempts to
pressure maintainers into endorsing third-party services without review.

Maintainers may close, edit, or remove issues and pull requests that are abusive,
unsafe, misleading, or unrelated to the project.
